# Contributing

Thanks for helping. `master` is protected: open a pull request, and it is
squash-merged once CI is green.

## Local setup

See the [README](README.md) for running the site with DDEV or with Hugo directly.
Package and tooling pages are generated from each package's README, so fix those
in the package repository, not here.

## Expectations

- Do not add private hostnames, IP addresses or personal email addresses to
  pages or fixtures. CI runs a leak scan.
